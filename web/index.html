How to Use & Deployment Guide

Click to expand/collapse step-by-step documentation

▼
1 GitHub Auth

Configure OAuth Client ID & Secret in the top-right settings. Click Authorize GitHub to sign in.

2 Connect VPS

Enter target VPS details. Run Test Connection, then click Bootstrap & Provision to install Docker/Caddy.

3 Analyze Repo

Search/select your repository, then run Analyze Tech Stack. (Note: A Dockerfile at the root is required!).

4 Deploy & CD

Copy VPS info, name your deployment, select a port, and click Bootstrap Deployment. This commits the CI/CD pipeline to GitHub.

5 Monitor & Control

Once active, click 📊 Open Monitoring Dashboard to stream live CPU/RAM metrics and log consoles.
